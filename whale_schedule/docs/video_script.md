# WhaleSchedule · B站视频分镜脚本（2 分钟版）

> 定位：**二次元壁纸展示向**（非教学）
> 目标时长：**约 2 分钟**（下面逐段合计约 142 秒 → 按第四节砍 22 秒即到 2:00）
> 音频：**无配音**，BGM 情绪推进 + 字幕
> 不放结束卡（按你要求）—— 结尾回到壁纸画面淡出，GitHub 地址靠视频简介承载

## 二、剪辑前必须准备（**不做这步录出来会很空**）

### 1. 演示数据

| 列 | 建议内容 |
|---|---|
| 课程名称 | 6~8 门真实感课名：高等数学、线性代数、大学物理、数据结构、操作系统、英语视听说、体育、毛概 |
| 雨课堂 / 云班课 / 智慧树 | **勾一半留一半** —— 全勾或全不勾都看不出"能勾" |
| 备注 | 写具体：「周一 1-2 节 · 教三楼 305」 |

### 2. 录屏方式

- ✅ 右键壁纸 → **Play in Window → Full HD Preview** → 全屏录制（画面干净，**无桌面图标**）
- ❌ 直接录桌面壁纸（桌面图标会入镜）
- **保留鼠标指针**（要展示点击与拖拽），Xbox Game Bar / OBS 均可
- 锁 **1920×1080 / 60fps**

### 3. 先关飘雪

飘雪每帧都在变，剪辑对不齐节奏。**留到片尾空镜再开。**

## 三、分镜

### 0:00–0:05 · 片头

| 项 | 内容 |
|---|---|
| 画面 | HTML 片头动画（另做）：深蓝紫渐变底 → 表格卡片淡入 → 鲸鱼娘从卡片边缘走出 → 标题逐字浮现 |
| 字幕 | `WhaleSchedule` / `课程管理壁纸` |
| 音乐 | 用一个明显 downbeat **卡在标题出现那一刻** |
| 备注 | 不超过 5 秒。B站观众对片头耐心极低 |

### 0:05–0:15 · 第一眼

| 项 | 内容 |
|---|---|
| 画面 | 整体静态展示，**极缓慢推近**；飘雪打开，鲸鱼娘在走 |
| 字幕 | `一张会自己走动的课程表` |
| 音乐 | 主旋律进来，节奏放缓 |
| 备注 | 这 10 秒决定观众留不留 |

### 0:15–0:28 · 点单元格就能改

| 项 | 内容 |
|---|---|
| 画面 | 点击单元格 → 输入框出现 → 输入（**英文/数字**，中文留给第 4 段）→ 点「确定」→ 内容更新 |
| 字幕 | `点单元格，直接改` |
| 音乐 | 保持 |
| 备注 | 别和键盘段重复演示中文 |

### 0:28–0:41 · 勾选框单击（**最该卡点的一段**）

| 项 | 内容 |
|---|---|
| 画面 | 连贯点击 4~5 个勾选框，**熟练、不犹豫** |
| 字幕 | `勾选框，单击就切换——不用先选中格子` |
| 音乐 | **每点一下卡一次拍** |
| 备注 | 最能体现"顺手"。别录得太慢 |

### 0:41–1:11 · 软键盘（**全片最长，功能亮点**）

| 项 | 内容 |
|---|---|
| 画面 | ① 点单元格 → 键盘自动弹出<br>② 拼 `hao` → 候选出「好号毫豪…」→ 点「好」上屏<br>③ 拼 `shi` → 点 `›` **翻页**到第 2 页<br>④ 按住标题栏**把键盘拖到别处** |
| 字幕 | `桌面模式下，壁纸收不到键盘按键` → `所以内置了软键盘` → `拼音输入 · 候选翻页 · 可拖动` |
| 音乐 | 键盘弹出瞬间可加轻音效（可选） |
| 备注 | 三句字幕按顺序出，**先解释"为什么"，再讲"怎么做"**，否则观众会疑惑为什么不用键盘 |

### 1:11–1:29 · 拖动 + 缩放 + 隐藏

| 项 | 内容 |
|---|---|
| 画面 | ① 拖工具栏移动面板<br>② 拉 `table_scale`：140% → 60%（平滑）<br>③ 取消 `table_visible` → 面板消失；重新勾上 → 回来 |
| 字幕 | `面板可拖动` / `整体等比缩放` / `一键隐藏` |
| 音乐 | 缩放时稍强 |
| 备注 | **把 WE 属性面板也录进去**，观众才知道在哪调 |

### 1:29–1:47 · 模板与数据

| 项 | 内容 |
|---|---|
| 画面 | 切换预设：学习 → 工作 → 生活（列结构明显变化）；导出 JSON |
| 字幕 | `三套预设 · 自定义模板` / `数据存本地，可导入导出` |
| 备注 | 模板切换**前后各留 1 秒**，让观众看清列名变化 |

### 1:47–2:09 · 鲸鱼娘（**氛围向的灵魂段落**）

| 项 | 内容 |
|---|---|
| 画面 | 特写鲸鱼娘，4 个表情依次：微笑 → 开心 → 惊讶 → 思考，每个约 3 秒；穿插"编辑时她思考""删行时她惊讶"的联动 |
| 字幕 | `编辑时她会思考` / `删掉一行，她会惊讶` / `她叫鲸鱼娘（大肥鱼）` |
| 音乐 | 旋律最柔处，或留一小段只留环境音 |
| 备注 | 特写可把她从素材里裁出来放大。**别省这段** |

### 2:09–2:22 · 收尾（**无结束卡**）

| 项 | 内容 |
|---|---|
| 画面 | 回到整体壁纸，飘雪打开，她继续走，**缓慢拉远**，最后淡出 |
| 字幕 | `纯本地 · 无网络请求` → `开源地址见简介` |
| 音乐 | 渐弱收尾 |
| 备注 | 按你要求不放二维码/结束卡，GitHub 地址写在**视频简介**里 |

## 四、怎么砍到 2:00

合计约 142 秒，**按顺序砍这 22 秒**：

| 砍哪里 | 省下 | 理由 |
|---|---|---|
| 第 2 段「点单元格就能改」压到 8s | 5s | 键盘段已展示输入，这段可快 |
| 第 6 段「模板与数据」压到 12s | 6s | 导出 JSON 对氛围向观众意义不大，只留模板切换 |
| 第 8 段「收尾」压到 8s | 5s | 拉远别拖太久 |
| 第 7 段「鲸鱼娘」压到 19s | 3s | 每表情 2.5s 也够看 |
| 第 1 段「第一眼」压到 8s | 2s | |

**不要砍**第 4 段（软键盘）和第 3 段（勾选卡点）—— 全片核心，砍了就没亮点。

## 五、片头动画方案（我来做）

| 时间 | 画面 | 实现 |
|---|---|---|
| 0.0–0.4s | 深蓝紫渐变底 + 光晕扩散 | `radial-gradient` + `opacity` |
| 0.3–0.8s | 表格卡片从下方淡入，0.96 → 1.0 放大 | `transform` + `opacity` |
| 0.7–1.2s | 鲸鱼娘从卡片左边缘走出站定（**真实素材**） | `translateX` + 素材切图 |
| 1.0–1.8s | 标题逐字淡入 + 模糊转清晰 | 逐字 `animation-delay` |
| 1.6–2.4s | 副标题打字机效果 | `width` + `steps()` |
| 2.4–4.5s | 整体缓慢推近 1.02 + 轻雪飘落 | `transform` + 复用飘雪 |
| 4.5–5.0s | 淡出 | `opacity` |

规格：1920×1080 全屏、纯 CSS、零外部依赖、可直接浏览器录屏。
