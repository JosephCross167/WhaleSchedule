【可编辑课程管理表格壁纸 · 大肥鱼陪你学习】

一张可以真正“用”的桌面壁纸——不只是看，还能管你的课程、任务和生活。
鲸鱼娘（大肥鱼）会在面板下沿来回溜达，陪你一起学。

■ 功能

· 多工作区（标签页）
表格上方是浏览器标签样式的工作区标签，点一下就能切换。
每个工作区连列结构和内容都是完全独立的，互不干扰：
课表放一个工作区、待办放另一个、生活安排再放一个，切来切去也不会串。
标签上带金点表示“这个工作区里有内容”；双击标签可重命名，点 ✕ 删除（删除前会先确认）。
内容实时保存，不用手动操作。

· 表格增删改
自由添加行、删除行；点击单元格后用内置软键盘编辑，也可打勾。

· 勾选框列
每门课的雨课堂、云班课、智慧树、MOOC、CG平台、实验、工图，点一下就能打勾。

· 模板
内置三套预设：学习 / 工作 / 生活；也可以把当前工作区的列结构存成自定义模板。
双击模板标签可重命名，右键或点 ✕ 删除。
载入模板前会弹窗确认——它会把模板的列结构套用到当前工作区，
覆盖该工作区现有的列和内容，以免误操作。

· 面板自由调
拖拽移动位置，WE 属性面板可调整体缩放比例、一键显示/隐藏，避开桌面图标和窗口。

· 大肥鱼陪伴
鲸鱼娘（大肥鱼）沿面板下沿来回走动，脚步不停。
新增行或新建工作区时她会开心转身，删除行/列/工作区或载入模板时她会惊讶转身，
编辑单元格时她会停下来思考。你学习，她溜达，互不打扰。

· 数据自动保存
表格内容、列结构、工作区都会保存在浏览器本地，关闭壁纸或重启电脑后仍保留。
也支持导出 / 导入 JSON 做备份或迁移（旧版本的数据会自动迁移，不会丢）。

■ 操作提示

· 切换工作区：点表格上方的标签页
· 新建工作区：点标签左侧的 ＋
· 重命名工作区：双击标签（模板同理，双击即可改名）
· 移动面板：拖动顶部工具栏
· 调整缩放：在 Wallpaper Engine 壁纸属性里调“表格缩放”滑块
· 显示/隐藏：在属性里切换“显示表格”
· 编辑表格：点击单元格 → 用软键盘输入或直接点勾选框

■ 键盘输入说明

在 Wallpaper Engine 的桌面模式下，壁纸收不到键盘按键（按键都被桌面图标接走了），
这是 WE 的限制。所以本壁纸内置了软键盘：点单元格后会弹出，用鼠标点击就能打字，
支持拼音输入中文，候选字按常用度排序。

如果你更想用真实键盘打字，可以右键壁纸 → Play in Window → 全屏预览，在预览窗口里编辑。

数据会自动保存，切回桌面壁纸后内容还在。
